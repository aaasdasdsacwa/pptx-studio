# Images and screenshots

Start with the explanatory job: show a real interface, physical context, a concrete example, or a deliberately illustrative concept. Prefer relevant assets already approved in the source deck.

For external material, use available search/download tools and retain its source and applicable attribution/license information. Use official sources for logos and actual product screenshots. Download only when the environment supports it; preserve the existing network and permission boundaries.

Use image generation when illustration is requested or helpful and a suitable generation tool is available. Label conceptual/generated illustrations appropriately when they could otherwise be mistaken for real evidence. It is optional, not a dependency of this skill.

Crop screenshots to the area being discussed, preserve readable labels, and add focused callouts or a magnified inset. Preserve aspect ratio and deliberate crops. Keep images out of text space unless an intentional overlay remains readable.

Record sources in notes or an accompanying asset list. Public examples use synthetic or explicitly redistributable material. If a required asset is unavailable, explain the specific gap and complete independent authorized work.

Completion: each image has a clear explanatory role, important detail remains legible, sources are traceable, and no generated or decorative material is represented as measured evidence.
