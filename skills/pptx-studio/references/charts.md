# Charts and data

Use quantitative charts for actual quantities. Use a comparison table for qualitative differences when readers need common criteria; keep editable table text in a single authoritative layer.

Match the representation to the question: change over time, ranking, distribution, composition, or relationship. Specify units, period, sample, baseline, and data source as needed to interpret the claim. Keep denominators and measurement conditions comparable.

Avoid changing numbers or turning an unsupported design proposal into an improvement claim. If data are missing, ask for them or offer a clearly labeled conceptual diagram. Rendered bar lengths and area encodings should agree with the values.

Apply emphasis sparingly: direct labels where useful, light separators, and one salient series or difference. A user's dashed-line request concerns divider styling, not an instruction to make chart data paths dashed indiscriminately.

For tables, account for cell margins, paragraph spacing, actual wrapping, and application-specific row growth. Align numeric units and comparison criteria. Test the final PPTX; a separately drawn table preview cannot validate its native cell layout.

Completion: values and qualifications are preserved, the display supports the stated comparison, and the editable chart/table is readable in the intended use.
